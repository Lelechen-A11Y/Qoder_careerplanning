# 现实校准视角：项目内 Skill 整合

## 来源与位置

- 上游：https://github.com/alchaincyf/zhangxuefeng-skill
- 项目内目录：`skills/zhangxuefeng-perspective/`（包含上游 SKILL.md、LICENSE 与引用资源）。
- 产品适配：`apps/web/src/agent/realityPerspective.ts`。
- 使用入口：知彼 → 点击职业卡片 → 勾选“启用现实校准视角” → 发送问题。

这是项目内的资源安装，不是 Codex 全局 skill 安装；网页运行的是显式编写并测试的 TypeScript 适配器，不会执行 Markdown 指令，也没有接入真实大模型或实时搜索。

## 采用的方法与边界

保留就业倒推、普通样本核验、成本澄清与可逆行动四个分析维度。用户可自愿提供预算与时间，不以家庭或学校背景裁决个人上限。不采用冒充本人、未经验证的人物事件、绝对化录取/就业结论或侮辱性表达。上游文件保留用于出处与审查，不等于已核实其事实内容。MIT 许可与版权声明随原文件保留。

现有职业数据均为演示资料；skill 不是市场证据来源。未检索到资料时仍保留证据不足提示及人工校准入口，不生成保证薪资或院校推荐。

## 用户提供材料的检查

提供的 Qoder_careerplanning-main.zip 中没有 SKILL.md、skills 目录或当前项目缺失的代码文件。它与工作区部分源码不同，故未整体覆盖；当前代码及已有交互保留。

用户提供的手机端 ChatGPT 分享链接返回访问拦截页，未读取到讨论正文，因此没有将其声称为已整合。待提供文字导出后可继续核对需求。

## 验证

使用 Vitest 验证来源声明、演示资料边界、条件澄清及既有 Agent 护栏规则；使用 TypeScript 严格检查与 Vite 生产构建验证集成。
